# koobubble 최신 전체본

## 포함 기능
- PC 화면 9:16 비율
- 모바일에서는 화면 전체
- 채팅방 제목: 건일 선배
- 상태문구: 파란 하트 + 980724
- 발신자 프로필: profile.jpg
- 기본 배경: 연한 회색
- 첫 방문 닉네임 설정 팝업
- 닉네임 브라우저 저장
- 우측 상단 ⋮ 버튼으로 닉네임 다시 설정
- 메시지 안의 @@@ 를 방문자 닉네임으로 자동 치환
- 닉네임 마지막 한글 글자에 받침이 있으면 자동으로 '이' 붙임
- 하단 입력창에서 직접 채팅 가능
- 내가 보낸 채팅은 오른쪽에 표시
- 내가 보낸 채팅은 같은 브라우저의 localStorage에 저장
- 2022-10-21 금요일 오전 11:14 첫 메시지 포함
