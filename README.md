# koobubble 기본틀

GitHub에 아래 파일을 모두 같은 위치에 올립니다.

- index.html
- style.css
- app.js
- data.js
- background.svg
- profile.jpg ← 직접 추가할 프로필 사진

## 중요한 점

`profile.jpg`는 상단 채팅방 제목용 이미지가 아닙니다.

실제 메시지가 생겼을 때:

[프로필 사진] 건일 선배
              말풍선

형태로 표시되는 발신자 프로필입니다.

상단은:
- 제목: 건일 선배
- 상태: 파란 하트 + 980724

로 표시됩니다.

현재 `MESSAGES = [];` 이므로 채팅 내용은 비어 있습니다.
